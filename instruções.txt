1 - criar Dockerfile e depois docker-compose.yml ---- arquivos

2 -  configurar o Dockerfile, o nosso container.

3 - configurar o docker-compose que é o nosso gerenciador de container

4 - docker.com é o oficial, iremos utlizar o podman como alternativa

5 -  configurando o podman:

  1 -  choco install podman-cli  --- ou --- winget install RedHat.Podman ---> instalar somente se já nao estiver instalado para verificar podman --version
        verificar se o wsl ja está instalado, se nao tiver ----> wsl --install
  2 -  pip install podman-compose

6 -  PRIMEIRO COMANDO PARA INICIAR O container
    1 - podman machine init

    2 - podman machine start

    3 - podman-compose build  --                *** podma-compose build --no-cache
    **** ATENÇÃO VERIFICAR AS VERSÕES DO PYTHON NO POETRY E NO CONTAINER >>> 
    FROM python:3.12-slim **CONTAINER
    requires-python = ">=3.12" ** NO PYPROJECT

7 - SUBIR O CONTAINER
    podman compose up -d

8 - verificar as variaveis de ambiente
        env_file:
      - .env
      2 - import os >>> para importar os arquivos
      em seguida mudar os nomes das variaveis no programa para buscar via .env
      ex.: 
      DATABASE_URL = "sqlite:///./livros.db"      --- antes 
      DATABASE_URL = os.getenv("DATABASE_URL")    --- Depois
